## 🍔 Kora

### Online Food Ordering & Delivery Platform

A modern food-ordering ecosystem consisting of a mobile application and backend API.

**Repositories**

* [`Kora`](https://github.com/Owen40/Kora) — Android application
* [`kora_backend`](https://github.com/Owen40/kora_backend) — Backend API

### Stack

**Mobile**

`Kotlin` • `Jetpack Compose` • `Android`

**Backend**

`Node.js` • `Express.js` • `PostgreSQL` • `JWT` • `REST API`

**Infrastructure / Services**

`Cloudflare` • `Object Storage` • `Email` • `Rate Limiting` • `Helmet`

The backend currently uses Express 5, PostgreSQL, JWT authentication, bcrypt, Helmet, CORS, rate limiting, AWS S3-compatible storage tooling, and email functionality.
